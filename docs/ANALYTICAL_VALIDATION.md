# Analytical Validation Note

## Assessment

**Share with caveats.** The SQL is reproducible and the highest-risk grain,
unit, duplicate and period rules are explicit. The baseline sources are not
contemporaneous, so the cross-source ratio is exploratory rather than a
performance KPI.

## Questions, sources and grain

| Question | Source and filter | Output grain | Main calculation |
|---|---|---|---|
| Largest allocation | CGD; `report_type = disbursement`, `expense_category = total`; exclude summary/total | entity × reporting period | sum of `allocated_million_baht` |
| Below median disbursement | Same CGD population; non-null rate only | entity × reporting period | exact median of the filtered `disbursement_pct` population |
| Workforce distribution | OCSC; `source_unit = person`; keep metric group/name separate | ministry × entity type × metric group × metric × FY | sum of `headcount` |
| Budget per civil servant | exact normalized entity-name match; aggregate each side before join | matched entity | selected budget basis / civil-servant headcount; basis is `allocated` when populated, otherwise `budget_after_transfer` |

## Evidence and checks

- Workbook profile: `data/processed/profile_summary.json` generated by the
  `profile` command; baseline shape is recorded in
  `config/source_manifest.json`.
- Parser evidence: CGD baseline produces 2,937 rows and OCSC baseline produces
  5,784 rows; raw cell counts are 93,237 and 32,653 respectively.
- Quality gate: required keys, source identity, numeric validity, non-negative
  measures, bounded rates, signed target variance, duplicate natural grain,
  reconciliation and baseline row-count collapse checks run before core
  publication.
- Join protection: the ratio query aggregates both sources to `entity_key`
  before joining, preventing a many-to-many multiplication of sums.
- Query files: [`analytics/queries`](../analytics/queries) are the exact SQL
  artifacts used for serving smoke checks.

## Caveats required before sharing

- OCSC is FY 2567 / 2024; CGD is FY 2569 / 2026 as of 3 July 2569.
- Exact normalized names are only candidate matches. A reviewed alias/master
  mapping is required before using the ratio operationally.
- Source-reported totals are retained for reconciliation; they are not silently
  substituted with platform-calculated totals.
- Percentages and counts are different measures. The workforce query never
  sums percentage or average-age rows as headcount.
- The baseline agency-level CGD rows have no populated `allocated` value, so
  the cross-source ratio uses `budget_after_transfer` and exposes
  `budget_basis` and `budget_million_baht_per_civil_servant`. This is an
  explicit source-semantic fallback, not an imputation.
- A result with no exact match is an absence of a conservative match, not proof
  that the organization does not exist in the other source.
